Example
{{ phone.data_updateinfo('', '1d' ) }}
This widget calls the configured phone service (Fritz!box TR-064 only!) and requests the "User Interface Info" which contains information on firmware updates. The information received is transferred to the following standard items while the "@" prefix marks the items as internal / not requested to the backend:
  • @phone.update.available: boolean notifier if update is available
  • @phone.update.version: new software version, if available
  • @phone.update.download: download URL if update available
  • @phone.update.info: URL for download information, if avaliable
The "repeat" parameter gives the update interval for the data.
