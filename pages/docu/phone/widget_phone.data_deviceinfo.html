{{ phone.data_updateinfo('', '1d' ) }}
This widget calls the configured phone service (Fritz!box TR-064 only!) and requests the "Device Info" which contains version information and log messages.

Important: the Fritz!Box User used for authentication must have configuration rights granted. Otherwise the information will not be sent via TR-064

The information received is transferred to the following standard items while the "@" prefix marks the items as internal / not requested to the backend:
  • @phone.deviceinfo.manufacturer: manufacturer name
  • @phone.deviceinfo.oui: manufacturers unique identifier for the product
  • @phone.deviceinfo.model: model name
  • @phone.deviceinfo.description: full model name with software version
  • @phone.deviceinfo.productclass: product class
  • @phone.deviceinfo.serialnumber: serial number
  • @phone.deviceinfo.software: software version
  • @phone.deviceinfo.hardware: hardware version
  • @phone.deviceinfo.spec: specification version
  • @phone.deviceinfo.uptime: uptime
  • @phone.deviceinfo.log: array of log messages, suitable for status.log()
The "repeat" parameter gives the update interval for the data.
