A simple button: inline pic, only text, inline pic and text, SVG pic and text - each in sizes 'mini' and 'midi'.
"Inline pics" are jQuery symbols originally delivered inline via CSS. Now, these are SVG pics with prefix "jquery_" but for backward compatibility reasons the prefix can be omitted.
